# Клиент: корзина интернет-магазина одежды (лаб. №24)

React-приложение (Vite) для управления корзиной интернет-магазина одежды. Работает автономно:
данные хранятся в `localStorage` под ключом `clothing-store:cart`. В лаб. №25 хранилище будет
заменено на REST API из корня репозитория.

## Запуск

```bash
cd client
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
```

## Функциональность

- **CRUD**: добавление товара (название, категория, размер, цвет, цена, количество), удаление,
  редактирование в строке, изменение количества кнопками `−`/`+`, очистка корзины.
  Повторное добавление того же товара того же размера и цвета увеличивает количество.
- **Фильтрация и сортировка**: поиск по названию/цвету, фильтр по категории, сортировка
  по дате, названию, цене и сумме позиции.
- **localStorage**: загрузка при монтировании (`useEffect(..., [])`), сохранение при каждом
  изменении списка; при отсутствии или повреждении данных — стартовый набор из 3 товаров.
- **Дополнительные эффекты**:
  - имитация загрузки с сервера (1 с) со спиннером;
  - автосохранение с debounce 500 мс и индикатором «Сохранение… / Сохранено в ЧЧ:ММ:СС»;
  - немедленное сохранение при закрытии вкладки (`beforeunload`), если debounce не успел сработать;
  - `document.title` показывает количество единиц в корзине;
  - статистика: позиций, единиц, средняя цена, сумма к оплате, сумма отфильтрованных позиций.
- **Горячие клавиши**: `Enter` — добавить товар / сохранить правку, `Escape` — отменить правку.

## Структура

```
src/
  App.jsx                    — шапка и корневой компонент
  components/CartList.jsx    — основной компонент: состояние, фильтры, сортировка, эффекты
  components/CartForm.jsx    — форма добавления (контролируемые поля, валидация)
  components/CartItemRow.jsx — строка корзины, редактирование (React.memo)
  components/CartStats.jsx   — блок «Итого»
  hooks/useLocalStorage.js   — загрузка/сохранение в localStorage, debounce, beforeunload
  data/catalog.js            — категории, размеры, стартовые данные, форматирование цены
  utils/validateItem.js      — валидация полей товара (форма и редактирование)
```
